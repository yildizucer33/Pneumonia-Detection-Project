#  Pneumonia Detection via Chest X-Ray Images

This project implements deep learning and transfer learning techniques to classify and detect pneumonia from pediatric chest X-ray images.

##  Overview & Methodology
- Preprocessed and augmented image datasets to prevent overfitting.
- Evaluated and benchmarked transfer learning architectures (such as VGG19, ResNet, and InceptionV3).
- Monitored training performance using multi-class confusion matrices, loss curves, and validation accuracy.

## 🛠️ Tech Stack
- Python
- PyTorch / TensorFlow / Keras
- OpenCV, Matplotlib, NumPy
